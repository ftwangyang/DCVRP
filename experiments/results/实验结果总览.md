# DCVRP 审稿补充实验：最终结果总览

## 0. 结论状态

所有实验均在 `experiments/` 隔离目录中实现和运行，未改写根目录中的原始方法文件。当前代码、原始逐实例结果、汇总表和论文级图片均已生成。

但实验结果**不支持直接保留论文原有的“DVNDA 显著优于强基线、独立参数化本身具有明确优势、简单微调可稳定扩展到 100 辆车”等表述**。在回复审稿人前，应修改方法论论证和结论措辞；否则会与新实验数据冲突。

另需注意：仓库中没有论文原始检查点、原始训练/测试划分或论文表格对应的逐实例数据。因此本次结果是干净的本地重新训练与统一协议评估，不是对论文既有数值的逐项复现。

## 1. 独立网络、共享网络与联合决策消融

统一训练预算下，每种架构使用 3 个独立训练种子，每个种子在同一组 100 个测试实例上评估。

| 架构 | 惩罚成本（均值） | 距离 | 完成 QoS | 平均响应时间/min |
| --- | ---: | ---: | ---: | ---: |
| Joint pair | **31.71** | 12.35 | **0.806** | 128.10 |
| Independent narrow | 33.99 | 9.07 | 0.751 | 166.01 |
| Independent（DVNDA） | 34.60 | **8.93** | 0.743 | 145.71 |
| Shared | 34.95 | 13.44 | 0.785 | 126.46 |
| Shared wide（近似等参数） | 34.98 | 13.85 | 0.789 | **120.61** |
| Shared + ID | 35.34 | 9.39 | 0.741 | 149.26 |
| Centralized | 38.75 | 13.45 | 0.747 | 125.35 |
| Attention aggregation | 40.54 | 11.92 | 0.714 | 133.19 |

关键结论：

- 联合 vehicle-customer 解码的平均惩罚成本最低，说明审稿人提出的“先选车再选客户可能限制搜索空间”具有数据依据。
- Independent 相对 Shared 仅降低约 1.01% 成本；3 个种子上的 Holm 校正后 `p=1.000`，不能宣称独立权重显著优越。
- Independent 有 46,724 个选择器参数；Shared-wide 为 45,889 个，等参数比较仍未显示独立参数化优势。

## 2. 聚合规则与车辆编号/顺序

| 规则 | 惩罚成本 | 距离 | 完成 QoS |
| --- | ---: | ---: | ---: |
| Argmax | **33.66** | **8.74** | 0.751 |
| Softmax sampling | 37.92 | 14.56 | **0.766** |
| Random vehicle | 38.55 | 14.74 | 0.762 |
| ID permutation | 33.66 | 8.74 | 0.751 |

- Softmax 与随机车辆的成本分别比 argmax 高 4.26 和 4.89，但 3 个种子下 Holm 校正均为 `p=0.259`。
- 8 种车辆子网络—车辆编号置换后，最大均值差约为数值舍入量；当前测试没有发现车辆顺序敏感性。
- 正比例缩放的 `tanh C={2,5,10,20}` 在贪心 argmax 推理时不会改变排序，因此四组推理结果完全相同。该结果只回答推理敏感性，不能替代“使用不同 C 重新训练”的探索性分析。

## 3. 固定间隔、事件触发与动态请求过程

| 设计 | 代表结果 |
| --- | --- |
| 规划区间数 6/8/10/12/14 | 成本分别为 34.73/33.56/33.84/35.14/35.32；8 个区间最低，但无单调规律 |
| Fixed/Event/Hybrid | 成本 33.64/31.99/32.58；事件触发最低 |
| Early/Uniform/Late | 成本 24.97/32.65/44.10；晚到请求最困难 |
| Two-peak/Clustered/NHPP | 成本 34.96/36.00/33.32 |
| 动态比例 0.10→0.90 | 成本 17.39→50.71，完成 QoS 0.924→0.565 |

该组结果直接回答了固定间隔人工等待、到达时刻分布、平均披露时间和高动态比例鲁棒性问题。事件触发调度优于固定间隔的本地均值结果，建议将其作为修订方法或至少作为限制讨论。

## 4. 旅行时间、服务时间与拥堵不确定性

| 情景 | 惩罚成本 | 完成 QoS | 响应时间/min |
| --- | ---: | ---: | ---: |
| Deterministic | **31.79** | **0.772** | 159.18 |
| Travel noise | 32.63 | 0.762 | 153.66 |
| Service noise | 35.16 | 0.737 | 153.90 |
| Joint noise | 33.74 | 0.754 | 150.65 |
| Peak congestion | 39.46 | 0.686 | 161.64 |

高峰拥堵造成最大性能退化，说明理想完成时间假设需要在正文中明确限制，并用不确定性结果补充。

## 5. 强传统基线与小规模最优解参考

统一滚动时域环境、相同完成定义和相同成本函数下：

| 方法 | 惩罚成本 | 完成 QoS | 规划时间/ms |
| --- | ---: | ---: | ---: |
| Nearest | **21.31** | **0.882** | **1.85** |
| Local search | 28.01 | 0.807 | 19.91 |
| Regret insertion | 28.11 | 0.807 | 16.28 |
| ALNS | 28.75 | 0.799 | 331.53 |
| Tabu | 29.00 | 0.797 | 28.38 |
| DVNDA | 33.19 | 0.756 | 62.58 |
| OR-Tools | 36.62 | 0.718 | 2512.24 |

当前 DVNDA 比最优的 Nearest 基线成本高 55.7%，也未超过 Local search、Regret、ALNS 或 Tabu。因此不能据此声称学习方法优于强滚动启发式。

在 20 个静态 `n=8, m=2` 小实例上，MIP 均求得 0 求解器 gap 的最优解。平均最优性差距为：OR-Tools 0.24%、ALNS 2.04%、Tabu 3.93%、Local search 6.42%、Regret 6.94%、Nearest 16.10%。这是静态小实例参考，不是动态在线问题的最优性界。

## 6. 真实有向路网与多城市泛化

使用 OpenStreetMap 的有向道路、单行比例和道路速度，在 Vienna、London、New York 各抽取 30 个实例，并对 3 个模型种子评估正常与高峰条件，共 540 行逐实例结果。

| 城市 | 正常：成本/QoS | 高峰：成本/QoS |
| --- | ---: | ---: |
| Vienna | 26.04 / 0.943 | 26.13 / 0.943 |
| London | 28.45 / 0.947 | 28.36 / 0.947 |
| New York | 25.74 / 0.938 | 26.04 / 0.937 |

路网规模分别为 Vienna 19,862 节点/41,525 有向边，London 24,146/52,352，New York 28,049/64,067；采样节点 ID 和 OSM 元数据均已保存。该实验解决了“单位正方形坐标不能代表真实拓扑”和“城市案例不足”的实验层面问题，但尚不能证明工业级交通预测有效性。

## 7. 参数、推理扩展与 m=10→100 迁移

| 选择器（m=100） | 参数数 | 决策延迟/ms | 峰值内存/MB |
| --- | ---: | ---: | ---: |
| Centralized | 21,441 | **0.67** | **9.49** |
| Shared | 11,681 | 1.10 | 34.68 |
| Independent | 1,168,100 | 4.86 | 43.78 |

Independent 参数量与车队规模线性增长；等价批量化后，m=100 的选择器延迟约为 Centralized 的 7.2 倍，峰值内存约为 4.6 倍。共享网络参数固定，但批量全车队推理同样以显存换速度。

m=100 的迁移均值：Independent 零样本 113.48，单步微调 117.51；Shared 零样本 179.87，单步微调 184.17。不同种子和规模有时改善、有时恶化，因此只能结论为“技术上可迁移，但短微调不稳定”，不能声称简单微调普遍有效。

## 8. 仿真状态、指标与统计修正

- 明确区分 unrevealed、revealed-unassigned、committed、en route、in service、completed、unserved。
- 区间结束时保留在途位置与服务进度，不再把已分配客户直接当成完成客户。
- 所有方法统一使用 `executed distance + 5 × unserved`，并报告响应时间、完成时间、未服务/迟到数、利用率、路线均衡、空闲等待、重规划次数和每决策时延。
- 使用 3 个独立训练种子作为神经模型统计重复层级；逐实例结果不伪装成独立训练重复。
- 架构和聚合比较提供配对检验与 Holm 多重比较校正。
- 8 个自动测试全部通过；正式原始结果的必要数值字段无缺失，成本恒等式最大误差仅为 CSV 浮点舍入量。

## 9. 建议用于返修的结论

1. 可以据实回复：状态转移、动态披露、强传统基线、最优性参考、多城市真实路网、扩展性、迁移和附加指标已经补齐。
2. 不应回复“独立网络已被证明显著优于共享/集中式网络”；现有证据不支持。
3. 不应保留“显著优于所有基线”；新滚动启发式结果与其相反。
4. 若必须维护原核心结论，需要找回论文原始检查点和数据划分，并进行更长、更稳定的重新训练；若仍不能超过基线，则应把论文贡献改写为环境建模/可解释消融或采用联合解码、事件触发等实证上更好的设计。
