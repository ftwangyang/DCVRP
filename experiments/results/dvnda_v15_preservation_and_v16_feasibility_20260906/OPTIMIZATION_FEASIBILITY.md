# DVNDA v15 保留与后续优化可行性审计

审计日期：2026-09-06

## 结论

v15 已作为冻结版本完整保留。本审计没有修改 v15 源码、训练权重、训练日志、测试原始结果或最终可视化，也没有启动 v16 训练。

当前剩余偏差不能通过“继续优化训练”合规地缩小。论文 Table I 的 DVNDA 目标为 `8.31 / 8.95 / 10.47 / 11.78`；v15 最终模型在中高动态率下的实测成本已经更低。训练目标本身是最小化路径成本，因此继续训练会使成本进一步下降，方向上反而远离 Table I。若在查看 Table I 后通过早停、挑种子、挑权重、修改损失或人为削弱策略把成本抬高，属于结果导向拟合，不能作为独立复现。

## 环境与成本口径审计

现有复现包的非学习 Greedy 行在四档动态率均能在约 1.8% 内复现 Table I。这说明实例分布、时间/容量语义和最终欧氏距离成本口径不是当前神经策略偏差的主要来源。

先前还排除了以下解释：

- 强制同步边界回仓会把 QoS 降到约 10%–41%，与论文约 100% 不符。
- 动态率混合方式不是原因。
- 发布版生成器比当前稿件生成器更差，而不是更接近。
- 免费等待和提前看到未披露客户均已通过执行轨迹与掩码测试排除。

综合证据表明，当前实现得到的是在高动态率下优于论文表格所对应策略的模型，而不是一个还能通过常规优化补上的性能缺口。

## 决策与合规后续

不建立或启动以“靠近 Table I”为目标的 v16。保留 v15 为当前最好、可审计、可复现版本。

只有出现新的、与原论文直接相关且未参与本次测试结果选择的证据时，才值得建立隔离版本，例如：

1. 原作者生成 Table I 的确切训练/评估源码及配置；
2. 原始 checkpoint、训练曲线、固定测试张量和逐实例结果；
3. 论文未披露的 checkpoint 选择或 customer decode 规则；
4. 能在不查看 Table I 测试误差的独立验证集上预先证明必要性的协议差异。

如果目标改为“进一步降低路径成本”，可以另立性能优化实验；但它应被报告为改进结果，而不是 Table I 复现。
